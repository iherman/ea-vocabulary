This document describes the , i.e., the RDFS [[RDF-SCHEMA]] vocabulary used by the EPUB Annotation, as a profile of the W3C Web Annotation vocabulary.

Alternate versions of the vocabulary definition exist in Turtle and JSON-LD.

Published:
2025-12-17
Version Info:
1.0
See Also: https://w3c.github.io/epub-specs/epub34/annotations/

This vocabulary has been defined by the W3C Publishing Maintenance Working Group and provides the official RDFS vocabulary for EPUB Annotations 3.4. Comments regarding this document are welcome. Please file issues directly on GitHub.

Term definitions

Class definitions

The following are class definitions in the ea namespace.

Annotation

EPUB Annotation Object

See the formal definition of the term.

The Annotation object of EPUB Annotation; the list of acceptable properties are restricted compared to the Web Annotation version.
Subclass of:
oa:Annotation
Range of:
items
Domain of:
target, body, motivation
Relevant @context:
https://wwww.w3.org/ns/epub/annotation/context

Creator

See the formal definition of the term.
